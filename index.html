Guia React

A Ana tem a padaria, o site de três páginas e um problema que cresce: o mesmo cabeçalho copiado em todo lugar, a lista de pães escrita à mão, e cada mudança de horário vira uma tarde de copiar e colar. Este guia ensina React do começo — o que é um componente, como o JSX vira HTML, como guardar dados que mudam, como buscar na rede — até o dia em que a página dela se monta sozinha e ela não repete mais nada. Escrito em português, para quem nunca programou.

Como este guia funciona
  • 144 aulas, uma ideia por aula, na ordem em que se aprende de verdade.
  • Toda caixa "Experimente" roda o seu componente com o React 19 de verdade (o pacote oficial, empacotado para o navegador) e mostra o HTML que ele gerou.
  • O JSX é transformado pelo Babel no seu navegador — o mesmo caminho de um projeto com Vite, só que na hora.
  • Não precisa instalar nada para começar: as caixas já trazem React e o transformador.

1. Para quem é

Para quem nunca escreveu uma linha de código e quer uma página que se atualize sozinha: contador que conta, lista que filtra, formulário que responde. O guia não supõe que você saiba JavaScript, HTML ou React: cada peça aparece quando é necessária, explicada na hora. Se você já programa, o Nível 1 vai parecer devagar — é de propósito. A leitora que este guia atende é a Ana, e a Ana ainda confunde "devolver" com "mostrar".

Se você já mexeu com React antes, comece pela Referência: são doze páginas de consulta, com tabelas de hooks, props, eventos e as mensagens de erro mais comuns, cada uma com o que fazer.

2. O primeiro componente, agora

Este é o mesmo componente que a primeira aula monta. Leia o código, clique em Rodar e veja o HTML que o React gerou. O React que roda esta caixa é o pacote oficial, versão 19 — o mesmo que você vai usar no seu projeto.

Missão: o componente devolve um título com "Oi" e nada mais. Faça ele devolver um h1 com Padaria da Ana e um p com Aberto das 6h às 18h, dentro de uma div.

function App() {
  return <h1>Oi</h1>;
}
<h1>Oi</h1>

function App() {
  return (
    <div>
      <h1>Padaria da Ana</h1>
      <p>Aberto das 6h às 18h</p>
    </div>
  );
}

O painel mostra o resultado: uma div com um h1 e um p. Não é uma imagem, nem uma promessa — é o HTML que o React montou a partir do seu JSX, lido do navegador depois de rodar. É assim que o guia confere tudo: pelo resultado, não pela aparência do código.

3. O que você vai construir

No fim do Nível 1, a Ana tem a página da padaria feita de componentes: um cabeçalho que recebe o nome por prop, uma lista de pães gerada com map e um contador de pedidos que funciona de verdade. No Nível 2, a página vira aplicação: formulário de encomenda com validação, tabela de pedidos que filtra e ordena, dados que vêm da rede com estado de carregando e de erro, e os hooks usados com critério — cada um com o problema que resolve.

No Nível 3, o assunto deixa de ser "fazer funcionar" e vira "fazer durar": criar o projeto com npm e Vite, entender o que cada script do package.json faz, organizar pastas, colocar rotas, publicar, medir o que está lento e usar o que há de novo no React 19 — actions, useActionState, useOptimistic.

4. Como estudar

Uma aula por vez, na ordem, com o editor aberto. Ler sobre componente não ensina componente: editar a caixa e ver o painel mudar, sim. Depois de cada aula, refaça o exercício no seu próprio arquivo e olhe o resultado no navegador com F12 → Elements. O painel do guia mostra o mesmo que o inspetor mostra, só que sem você precisar procurar.

Não adivinhe: leia o HTML gerado

Quem começa tenta descobrir o resultado relendo o JSX. O caminho certo é o contrário: rodar e ler o que o React produziu. Se o painel mostra um elemento a mais, é porque o seu componente devolveu um elemento a mais — e é ali que está a lição.

5. O que este guia não é

Não é a documentação oficial: para a lista completa de APIs existe o site do React, e a Referência aponta o caminho. Não é um curso de JavaScript avançado: o que aparece de linguagem é explicado na hora. E não é um curso de servidor: quando o assunto é backend, o guia usa uma API de exemplo e diz com todas as letras que aquele pedaço não é React.
